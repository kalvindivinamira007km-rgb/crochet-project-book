# Crochet Project Book

A one-page app for planning crochet projects.

- **Projects:** colors, yarn type and weight, skeins needed, hook size, tutorial link (TikTok, YouTube, Facebook, Pinterest…), pattern link or notes, photos, row counter, cost and hours.
- **Yarn stash** and a **To buy** list that subtracts what you already own.
- **Find patterns:** a short picture quiz (technique → project → level) that opens free-pattern searches on Ravelry, YouTube, TikTok, Pinterest, Facebook and Google.
- **Make a pattern:** turn a photo into an exact colorwork chart (C2C, tapestry, graphghan, 2-color mosaic, filet) with row-by-row instructions and yarn estimates.

Everything is saved in your browser on each device. Use **Download backup** and **Import backup** on the Projects tab to copy your projects between your phone and laptop.

AI-written patterns from a photo are only available in the Claude version of the app.

The whole app is a single `index.html` file with no build step.
